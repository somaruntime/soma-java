# SOMA 品牌资产

本目录保存与 SOMA 产品身份一起延续的品牌资产：

- `soma-logo.png`：640 × 640 的正式 Logo 与 GitHub 头像；
- `soma-banner.png`：2400 × 640 的 README 与产品介绍 Banner；
- `soma-original.png`：2048 × 2048 的高分辨率原始视觉资产，用于后续生成或
  更新正式衍生图。

`soma-original.png` 是应受版本控制保护的品牌源文件，不是构建输入，也不应被
运行时代码或发布包自动携带。
